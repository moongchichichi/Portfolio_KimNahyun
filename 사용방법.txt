1. index.html을 브라우저에서 여세요. 설치나 서버 없이 동작합니다.
2. 상단의 네 목차를 누르면 각 프로젝트로 이동합니다. 스크롤해도 상단 정보는 고정됩니다. 날짜·책 정보·제작 사양은 챕터별로 한 번에 나열되며, 같은 챕터 안에서는 스크롤해도 바뀌지 않습니다.
3. 이미지를 누르면 크게 볼 수 있습니다. Escape 키나 닫기 버튼으로 닫습니다.

이미지 교체
- images 폴더에 화면에 표시된 파일명으로 이미지를 넣으세요. 파일 목록은 images/파일목록.txt에 있습니다.
- 예: images/hangeul-poster.jpg
- PNG, WebP, GIF, SVG 등으로 바꾸려면 index.html을 텍스트 편집기로 열고 IMAGE_FILES를 검색하세요. 해당 경로의 파일명과 확장자를 바꾸면 됩니다.
- 각 이미지는 PDF에서 추출한 작은 미리보기로 표시됩니다. 실제 파일이 있으면 자동으로 교체되고 파일명 표시는 숨겨지며, 파일이 없거나 읽을 수 없으면 미리보기를 유지합니다.
- 브라우저를 새로고침하면 교체 결과를 확인할 수 있습니다.
- 다른 비율의 파일은 원본의 전체가 보이도록 contain으로 표시됩니다. 채워 넣으려면 .image-button img의 object-fit을 cover로 바꾸세요.
- 새 글자에는 Pretendard Medium(설치되어 있다면)을 우선 사용합니다. 다른 기기에서는 시스템 한글 글꼴로 표시됩니다.

구성
- index.html: HTML, CSS, JavaScript, 미리보기가 모두 들어 있는 단일 파일
- images/: 나중에 넣을 원본 이미지 폴더
- 외부 라이브러리, 계정, 업로드 기능은 필요하지 않습니다.
- 배포할 때 index.html과 images 폴더를 함께 올리세요.

원본의 17쪽을 표지·목차를 합친 고정 헤더, 네 프로젝트, 마지막 인사로 옮겼습니다.
프로젝트 순서와 번호는 PDF 목차 기준입니다(한글 세로쓰기 → 아카이브 → 에디션 → 종이나라).
PDF의 그래픽은 미리보기에 보존했습니다. 원본의 날짜·제작 정보는 그대로 옮겼습니다.
상단은 데스크톱에서 4단으로 나뉩니다. 글자 그리드는 좌우 여백 안에 배치하며 Portfolio와 아래 정보는 첫 번째 단, 목차는 세 번째 단, 이름과 연락처는 네 번째 단에 놓입니다. 상단 바는 투명합니다. 데스크톱에서는 고정 글자 사이의 두 번째 세로 영역에 대표 사진을 크게 배치하고, 나머지 사진은 양옆에 작게 표시합니다. 모든 사진과 본문은 스크롤할 때 가려지지 않고 투명한 상단 글자 뒤로 지나갑니다. 원본 이미지 비율은 유지합니다. 데스크톱은 네 열, 태블릿은 최대 세 열, 모바일은 두 열입니다.

책1 실제 이미지
- 01번: 원본 PDF 둘째 페이지가 왼쪽, 첫 페이지가 오른쪽입니다.
- 02·03번: 파일명 끝 -2가 왼쪽, -1 또는 _1이 오른쪽입니다.
- 웹에서 사용하는 합본은 images/hangeul-book1-01-spread.jpg부터 03-spread.jpg까지입니다.
- 원본 PDF는 그대로 보관했습니다. PDF 교체만으로 합본 이미지가 자동 갱신되지는 않습니다.

추가 이미지 반영
- 책2는 01·03·04·05·07번을 -2 왼쪽, -1 오른쪽으로 합쳤습니다. 파일 없는 02·06번은 표시하지 않습니다.
- 조판 가이드 01·02·03 PDF는 JPG로 변환했습니다. 아카이브 PNG와 포스터 JPG도 반영했습니다.

- 나머지 미리보기는 처음 제공한 포트폴리오 PDF에서 가져온 이미지입니다.

1번·3번 작품 갤러리는 왼쪽 작은 열과 오른쪽 큰 두 열로 배치하며 가운데는 비웁니다. 2번·4번 배치는 유지합니다.

첫 화면은 네 작업의 썸네일을 한 화면에 보여줍니다. 썸네일이나 목차를 누르면 해당 인트로부터 상세 사진이 이어집니다. 상세 화면에서는 목차와 이름·연락처를 숨깁니다. Back 또는 Portfolio로 첫 화면에 돌아오면 다시 표시됩니다. 프로젝트 주소(#hangeul 등)로 직접 열면 해당 프로젝트로 이동합니다.

최근 수정: 아카이브 전체·낱장 콜렉션 PNG와 종이나라 인트로 PNG를 연결했습니다. 너비 1000px 이하에서는 고정 본문과 상세 정보를 일반 흐름으로 전환하고 사진을 2열로, 560px 이하에서는 1열로 배치합니다. 아카이브 문장부호 자료와 콜렉션 묶음은 2열을 유지합니다.
